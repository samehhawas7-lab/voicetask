# اختبارات مصر VPN

المشروع نفسه بلا أيّ حزمة خارجية. وهذه الاختبارات تقابل نتائجه بمراجع مستقلّة:
مكتبة `crypto` في Node للمفاتيح، و`jsQR` لقراءة الرمز، ومتصفّح Chromium حقيقيّ للواجهة.

```bash
./run.sh        # الأساسية: البوّابة وأنفاقها — بلا تثبيت شيء
npm install && ./run.sh all   # ومعها المفاتيح والرمز والواجهة
```

يضيف السكربت سطراً إلى `/etc/hosts` (`test.masr.local`) ويولّد شهادة محلّية،
لأنّ البوّابة ترفض عناوين الشبكة الداخلية عمداً فلا يمكن اختبارها بـ `127.0.0.1` مباشرةً.

## ماذا يُختبَر

| الملفّ | الموضوع |
|---|---|
| `lab.js` | موقع تجريبيّ + نفق `CONNECT` + نفق `SOCKS5` + عدّاد يثبت أنّ الطلب مرّ بالنفق |
| `test.js` | إعادة كتابة الروابط، الكعكات المعزولة، التحويلات، الضغط، POST، الحماية، **وألّا يخرج طلبٌ مباشرةً إذا سقطت البوّابة** |
| `fieldtest.js` `ladder.js` | حساب المنحنى مقابل `BigInt`، ومتّجه RFC 7748 |
| `wgtest.js` `wgtest3.js` | المفتاح العامّ مقابل Node، في مساري WebCrypto والتنفيذ الداخليّ |
| `qrdecode.js` | الرمز يُفكّ بقارئ مستقلّ: إصدارات وأقنعة ومستويات تصحيح وعربيّة |
| `qrtest.js` | مقابلة الشبكة وحدةً وحدةً بمكتبة `qrcode` |
| `ui.js` | الواجهة في Chromium: التبويبات، توليد المفاتيح، التحقّق من المدخلات، تصويرُ الرمز وفكُّه، والتصفّح عبر البوّابة |

`dev.js` خادمٌ محلّيّ يشغّل دوالّ `/api` كما تعمل عند النشر.
