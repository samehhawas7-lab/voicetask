# ريموت KMC — تطبيق ويب للتحكم بالتلفزيون

تطبيق ويب تفتحه من جوالك أو الكمبيوتر وتتحكم فيه بالتلفزيون: التنقل، الصوت،
التشغيل، فتح يوتيوب ونتفلكس، وحتى الكتابة في مربعات البحث.

<div dir="ltr">

```
جوالك (متصفح)  ──HTTP──▶  خادم محلي (كمبيوتر/راسبيري باي)  ──TLS──▶  تلفزيون KMC
```

</div>

---

## ⚠️ اقرأ هذا أول — شرطان أساسيان

**1) التلفزيون لازم يكون Android TV أو Google TV**

التطبيق يستخدم بروتوكول *Android TV Remote Service v2* — نفس البروتوكول اللي
يستخدمه تطبيق «Google TV» الرسمي و Home Assistant.

للتأكد: افتح شاشة التلفزيون الرئيسية. إذا كانت تعرض صفوف تطبيقات بنمط
Android TV، أو فيه «متجر Google Play» بالتلفزيون → يشتغل معك.
شاشات KMC العادية (غير الذكية) أو اللي تشتغل بأنظمة أخرى **ما تشتغل** —
تحتاج جهاز إرسال أشعة تحت الحمراء (IR blaster) وهذا خارج نطاق هذا المشروع.

**2) الخادم لازم يشتغل على جهاز داخل نفس شبكة التلفزيون**

ما ينفع ترفعه على Vercel أو أي استضافة سحابية، لأن السيرفرات السحابية
ما توصل لشبكة بيتك. شغّله على:
لابتوب، كمبيوتر مكتبي، راسبيري باي، أو جوال أندرويد فيه Termux.

## التشغيل

<div dir="ltr">

```bash
cd tvremote
npm install
npm start
```

</div>

بيطلع لك:

<div dir="ltr">

```
  KMC Web Remote شغّال
  محلياً:  http://localhost:8099
  الشبكة:  http://<IP جهازك>:8099   (192.168.1.x)
```

</div>

افتح الرابط من جوالك (لازم الجوال على نفس الواي فاي).

## الإقران — أول مرة فقط

1. شغّل التلفزيون وخلّه على الشاشة الرئيسية.
2. افتح التطبيق واضغط **🔍 ابحث عن التلفزيون في الشبكة** — بيمسح الشبكة
   ويعطيك العناوين اللي فيها خدمة الريموت شغّالة. أو اكتب عنوان IP يدوياً
   (تلقاه في: إعدادات التلفزيون ← الشبكة ← حالة الشبكة).
3. اضغط **توصيل**. بيظهر على شاشة التلفزيون رمز من 6 أرقام.
4. اكتب الرمز في التطبيق واضغط **تأكيد**.

بعد كذا يتم حفظ شهادة الإقران في `data/tv.json`، والتطبيق يتصل تلقائياً
كل مرة تشغّل فيها الخادم — ما تحتاج تعيد الإقران.

> إذا ما ظهر رمز على التلفزيون: تأكد إن التلفزيون مشغّل فعلاً (مو في وضع
> السكون)، وإنه على نفس الشبكة، وإن الجوال والكمبيوتر على نفس الواي فاي
> (مو أحدهم على شبكة الضيوف).

## المميزات

| الميزة | التفاصيل |
|---|---|
| التنقل | عجلة اتجاهات + OK + رجوع + الرئيسية |
| الصوت | رفع/خفض/كتم — **ضغطة مطوّلة = تكرار سريع** |
| القنوات | أعلى/أسفل + الدليل + معلومات + الترجمة |
| التشغيل | تشغيل/إيقاف، تقديم، إرجاع، التالي، السابق |
| التطبيقات | يوتيوب، نتفلكس، شاهد، Prime Video |
| الكتابة | تكتب في التطبيق ويظهر بالتلفزيون (إنجليزي وأرقام فقط) |
| لوحة الأرقام | 0-9 للقنوات |
| لوحة مفاتيح الكمبيوتر | الأسهم، Enter، Escape، مسافة، `+` `-` `m` |
| حالة مباشرة | يعرض التطبيق الشغّال حالياً على التلفزيون |
| إعادة اتصال | تلقائية لما يطفى التلفزيون ويرجع يشتغل |

## الحماية

**افتراضياً الخادم مفتوح لأي جهاز في شبكتك.** داخل شبكة بيتك عادةً مقبول،
لكن لو تبي تقييد:

<div dir="ltr">

```bash
REMOTE_TOKEN=اكتب-رمز-سري-هنا npm start
```

</div>

وبعدها افتح الرابط مع الرمز:
`http://192.168.1.5:8099/?token=اكتب-رمز-سري-هنا`

**لا تعرّض هذا الخادم على الإنترنت** (بدون port forwarding). لو تحتاج توصل
له من برّا البيت، استخدم VPN مثل Tailscale أو WireGuard.

## إعدادات إضافية

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `PORT` | `8099` | منفذ الخادم |
| `BIND` | `0.0.0.0` | عنوان الاستماع (`127.0.0.1` = محلي فقط) |
| `REMOTE_TOKEN` | فارغ | رمز الحماية |

## تشغيل دائم (اختياري)

عشان يشتغل تلقائياً مع إقلاع الجهاز على لينكس/راسبيري باي:

<div dir="ltr">

```bash
sudo tee /etc/systemd/system/kmc-remote.service >/dev/null <<'EOF'
[Unit]
Description=KMC Web Remote
After=network-online.target

[Service]
WorkingDirectory=/home/pi/voicetask/tvremote
ExecStart=/usr/bin/node server.js
Environment=PORT=8099
Restart=always
User=pi

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable --now kmc-remote
```

</div>

## حل المشاكل

**«ما لقيت أي تلفزيون» عند البحث**
البحث يمسح شبكات `/24` فقط. لو شبكتك أوسع، اكتب عنوان IP يدوياً.
تأكد كذلك إن التلفزيون مشغّل — وهو نائم ما يرد.

**«فشل الاتصال بالتلفزيون»**
التلفزيون مطفي، أو العنوان غلط، أو التلفزيون مو Android TV.
جرّب: `nc -vz <عنوان-التلفزيون> 6466` — لازم يقول succeeded.

**«التلفزيون ألغى الإقران»**
صار إعادة ضبط للتلفزيون أو حذفت الجهاز من إعداداته. أعد الإقران من جديد.

**الكتابة العربية ما تنرسل**
البروتوكول يرسل أزرار لوحة مفاتيح، ما يرسل نص خام — فالحروف العربية
ما لها أزرار. الإنجليزي والأرقام فقط. للبحث بالعربي استخدم البحث الصوتي
من ريموت التلفزيون الأصلي.

### واجهة API

كل المسارات تحت `/api`. مفيدة لو تبي تربطها بشيء ثاني
(مثلاً أوامر واتساب من بوت VoiceTask في نفس المستودع).

| المسار | الطريقة | الوظيفة |
|---|---|---|
| `/api/state` | GET | الحالة الحالية |
| `/api/events` | GET | بث مباشر للحالة (SSE) |
| `/api/connect` | POST | `{host, forcePair?}` |
| `/api/code` | POST | `{code}` رمز الإقران |
| `/api/key` | POST | `{key}` — القائمة في `/api/keys` |
| `/api/power` | POST | زر الطاقة |
| `/api/app` | POST | `{app}` أو `{link}` |
| `/api/text` | POST | `{text}` |
| `/api/disconnect` | POST | قطع الاتصال |
| `/api/forget` | POST | `{host}` حذف الإقران |
| `/api/discover` | GET | البحث في الشبكة |
