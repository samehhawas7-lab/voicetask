# ريموت KMC — نسخة webOS ✅ هذي النسخة الصحيحة لتلفزيونك

تلفزيونك يشتغل بنظام **webOS Hub**، وهذا خبر ممتاز:
المتصفح يقدر يكلّم التلفزيون **مباشرة** بدون أي خادم ولا أجهزة إضافية.

الملف: **`/tv.html`** في جذر المستودع (ملف واحد مستقل، ما يحتاج تنصيب).

<div dir="ltr">

```
سفاري في آيفونك  ──WebSocket──▶  تلفزيون KMC (webOS)
```

</div>

بيانات تلفزيونك من الصور:

| | |
|---|---|
| النظام | webOS Hub |
| عنوان IP | `192.168.8.77` |
| البوابة | `192.168.8.1` |
| MAC | `18:EF:3A:00:42:03` |

> عنوان IP ممكن يتغير بعد إعادة تشغيل الراوتر. لو وقف التطبيق فجأة،
> راجع العنوان من: الإعدادات ← الاتصال ← Wi-Fi ← متقدم.
> والأفضل: ثبّت العنوان من إعدادات الراوتر (DHCP Reservation).

---

## طريقتان لفتح التطبيق

### الطريقة ١ — احفظ الملف في جوالك ⭐ الأضمن

1. افتح `tv.html` من الجوال واحفظه في تطبيق **«الملفات»**
2. افتحه من «الملفات» — بينفتح في سفاري
3. اكتب `192.168.8.77` واضغط توصيل

ليش هذي الأضمن: الصفحة تنفتح محلياً، فالمتصفح يسمح بالاتصال المباشر
بالتلفزيون بدون أي تعقيدات شهادات.

### الطريقة ٢ — من الرابط على Vercel

الملف موجود في جذر المستودع، فبينشر تلقائياً مع مشروعك:

<div dir="ltr">

```
https://voicetask-swart.vercel.app/tv.html
```

</div>

**بس فيه خطوة إضافية مرة وحدة:** الصفحة على HTTPS، والمتصفح يرفض
يكلّم التلفزيون إلا عبر اتصال مشفّر موثوق. سوِّ التالي:

1. افتح في سفاري: `https://192.168.8.77:3001`
2. بيطلع تحذير أمان ← «إظهار التفاصيل» ← «زيارة هذا الموقع»
3. ارجع لصفحة التطبيق واضغط توصيل

التطبيق يكتشف الحالة ويعرض لك هذي الخطوات لو فشل الاتصال.

---

## الإقران — مرة وحدة

أول ضغطة على «توصيل» بيظهر على شاشة التلفزيون سؤال:
هل تسمح لهذا الجهاز بالتحكم؟ اضغط **موافق** بريموت التلفزيون الأصلي.

بعدها يُحفظ مفتاح الوصول في متصفح جوالك، وكل مرة يتصل تلقائياً.

---

## ⚠️ حد واحد مهم: ما يقدر يشغّل التلفزيون

| العملية | تشتغل؟ |
|---|---|
| إطفاء التلفزيون | ✅ |
| **تشغيل التلفزيون وهو مطفي** | ❌ |

السبب: تشغيل التلفزيون يحتاج إرسال حزمة Wake-on-LAN، وهذي تحتاج
بروتوكول UDP — والمتصفحات ممنوعة منه تماماً. هذا حاجز في المتصفح نفسه
مو نقص في التطبيق.

يعني: تشغّل التلفزيون بالريموت الأصلي، وبعدها كل شي من جوالك.

## الاختبار المحلي (للمطوّر)

فيه تلفزيون webOS وهمي للاختبار بدون تلفزيون حقيقي:

<div dir="ltr">

```bash
cd tvremote && npm install
node webos/mock-tv.js 3000
```

</div>

بعدها افتح `tv.html` في المتصفح واكتب `127.0.0.1`.
نقطة `http://127.0.0.1:3000/__log` ترجع كل الأوامر اللي وصلت التلفزيون الوهمي.

## كيف يشتغل تحت الغطاء

بروتوكول **SSAP** الخاص بـ webOS على قناتين:

| القناة | العنوان | الاستخدام |
|---|---|---|
| التحكم | `ws://<ip>:3000` أو `wss://<ip>:3001` | أوامر JSON: صوت، تطبيقات، نص |
| الأزرار | مقبس ننتزع عنوانه من التلفزيون | التنقل (أسرع بكثير) |

التطبيق يجرّب `ws://` أول (بدون مشاكل شهادات)، وإذا كانت الصفحة على HTTPS
يستخدم `wss://` مباشرة لأن المتصفح ما يسمح بغيره.
