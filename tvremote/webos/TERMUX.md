# تشغيل الريموت من جوال أندرويد (هواوي مات برو)

الغاية من هذا الدليل: تحويل جوال أندرويد إلى خادم صغير يظل شغّالاً في
البيت. عندها **تعمل أزرار التنقل ولوحة اللمس** — وهي الوحيدة التي يمنعها
التلفزيون عن المتصفحات.

<div dir="ltr">

```
آيفونك (سفاري) ──HTTP──▶ جوال هواوي ──wss──▶ التلفزيون
                          (أذونات كاملة)
```

</div>

السبب: التلفزيون يفحص من يكلّمه. المتصفح يُعرَّف نفسه فيُقيَّد، والبرنامج
العادي لا يفعل فيُمنح أذوناته كاملة.

---

## ١) تنصيب Termux

جوالات هواوي الحديثة بلا متجر Google، فننزّل الحزمة مباشرة:

1. افتح متصفح الجوال واذهب إلى **f-droid.org/packages/com.termux**
2. نزّل أحدث ملف APK
3. عند التنصيب سيحذّرك الجهاز من «مصادر غير معروفة» — اسمح له

> **لا تنزّل Termux من متجر Google Play** — تلك النسخة قديمة ومهجورة ولن
> تعمل. النسخة الصحيحة من F-Droid.

---

## ٢) تجهيز البيئة

افتح Termux واكتب الأوامر سطراً سطراً:

<div dir="ltr">

```bash
pkg update -y && pkg upgrade -y
pkg install -y nodejs git
```

</div>

ثم اجلب المشروع:

<div dir="ltr">

```bash
git clone https://github.com/samehhawas7-lab/voicetask
cd voicetask/tvremote
npm install
```

</div>

---

## ٣) التشغيل

<div dir="ltr">

```bash
cd ~/voicetask/tvremote/webos
TV_IP=192.168.8.77 node server.js
```

</div>

سيظهر لك:

<div dir="ltr">

```
  ريموت KMC — الخادم يعمل

  افتح من جوالك:
     http://192.168.8.xx:8099
```

</div>

**افتح هذا العنوان من سفاري في الآيفون.** بلا شهادات ولا اختصارات — ويعمل
كل شيء بما فيه التنقل ولوحة اللمس.

> العنوان الظاهر هو عنوان **جوال هواوي** لا التلفزيون. سجّله في المفضلة.

---

## ٤) إبقاؤه شغّالاً

أندرويد يوقف التطبيقات الخاملة. لمنع ذلك:

**امنع إيقاف Termux**
الإعدادات ← البطارية ← تشغيل التطبيقات ← Termux ← **إدارة يدوية**،
وفعّل الخيارات الثلاثة (تشغيل تلقائي، تشغيل غير مباشر، عمل بالخلفية).

**أبقِ المعالج مستيقظاً**
اسحب شريط إشعارات Termux للأسفل واضغط **ACQUIRE WAKELOCK**.

**اتركه مشبوكاً بالكهرباء** وواي فاي البيت.

---

## ٥) تشغيل تلقائي عند إقلاع الجهاز (اختياري)

<div dir="ltr">

```bash
pkg install -y termux-boot
mkdir -p ~/.termux/boot
cat > ~/.termux/boot/tvremote <<'EOF'
#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
cd ~/voicetask/tvremote/webos
TV_IP=192.168.8.77 node server.js
EOF
chmod +x ~/.termux/boot/tvremote
```

</div>

نزّل تطبيق **Termux:Boot** من F-Droid وافتحه مرة واحدة ليعمل.

---

## ٦) تثبيت العناوين

عنوانا التلفزيون وجوال هواوي قد يتغيّران بعد إعادة تشغيل الراوتر، فيتوقف
كل شيء. ثبّتهما من إعدادات الراوتر (**DHCP Reservation**) مرة واحدة
وتنتهي المسألة.

---

## حل المشكلات

| ما يحدث | السبب والعلاج |
|---|---|
| `node: command not found` | لم يكتمل `pkg install nodejs` — أعده |
| الصفحة لا تفتح من الآيفون | الجهازان على شبكتين مختلفتين، أو العنوان تغيّر |
| `تعذّر الوصول للتلفزيون` | التلفزيون نائم، أو `TV_IP` خطأ |
| يتوقف بعد دقائق | لم يُضبط WAKELOCK أو إعدادات البطارية |
| أزرار التنقل ما زالت معطّلة | تحقق أن الصفحة مفتوحة من عنوان **هواوي** لا التلفزيون |

---

## للتحقق من أنه يعمل

من متصفح الآيفون افتح: `http://<عنوان-هواوي>:8099/health`

يفترض أن يردّ: `{"ok":true,"tv":"192.168.8.77"}`
