# شبكة البيت 🏠

تطبيق لإدارة إنترنت المنزل: **يريك أي جهاز فتح أي موقع**، ويحجب ما تريد، ويقطع النت
عن جهاز واحد أو عن البيت كله بضغطة، وينبّهك فوراً إذا حاول أحد الأولاد فتح موقع
إباحي أو ميسر أو برنامج تجاوز فلترة.

كل شيء يشتغل داخل بيتك، بلا سحابة وبلا اشتراك، ولا يخرج سجل التصفّح من جهازك.
بلا أي مكتبة خارجية — Node.js فقط.

---

## كيف يشتغل؟ (الفكرة في سطرين)

قبل أن يفتح أي جهاز أي موقع، لازم يسأل «خادم DNS»: *وين عنوان `youtube.com`؟*
فإذا صار خادم DNS للبيت هو **جهازك أنت**، فأنت ترى كل سؤال، وتقدر ترد بعنوان
خاطئ (= حجب) أو تمرّره (= سماح). هذي نفس فكرة Pi-hole و NextDNS، لكن بلوحة
عربية وبقواعد مبنية للعائلة: ملفات لكل ابن، أوقات نوم، تنبيهات فورية.

```
جهاز الابن ──سؤال DNS──►  خادم البيت (هذا التطبيق)  ──►  1.1.1.1
                              │
                              ├─ يسجّل: من سأل، وعن أي موقع، ومتى
                              ├─ يقرر: يمرّر أو يحجب
                              └─ ينبّهك عند المواقع الخطرة
```

---

## ماذا يرى؟ وماذا لا يرى؟ (اقرأ هذا قبل كل شيء)

**يرى:**
- اسم كل موقع فتحه كل جهاز، بالوقت والتاريخ (`youtube.com`, `snapchat.com`, …).
- التطبيقات أيضاً، لأنها تسأل DNS مثل المتصفح تماماً.
- محاولات فتح المواقع المحجوبة — حتى لو ما فُتحت.

**لا يرى:**
- الصفحة المحدّدة داخل الموقع ولا كلمات البحث ولا محتوى المحادثات.
  لأن HTTPS يشفّر كل ما بعد اسم الموقع. أي تطبيق يعدك بالرابط الكامل يحتاج
  تركيب «شهادة اعتراض» على كل جهاز، وهذا يكسر أغلب التطبيقات ويُعتبر تجسّساً
  فعلياً — ولا ننصح به.
- ما يجري على **بيانات الجوال (4G/5G)**، لأنه لا يمرّ بشبكة البيت أصلاً.

**يمكن الالتفاف عليه** بثلاث طرق، ولها علاج في قسم [منع الالتفاف](#منع-الالتفاف):
VPN، أو DNS مشفّر داخل المتصفح (DoH)، أو تغيير إعدادات DNS يدوياً في الجهاز.

---

## المتطلبات

- جهاز يظل شغّالاً في البيت: **راسبيري باي**، أو لابتوب قديم، أو أي كمبيوتر
  متصل بالراوتر (يُفضّل بسلك).
- **Node.js 18** فأحدث.
- إمكانية دخول إعدادات الراوتر (لتغيير خادم DNS).

## التشغيل

```bash
cd homenet
node server.js          # يحتاج صلاحية المنفذ ٥٣
```

المنفذ ٥٣ محجوز للنظام، فعلى لينكس/ماك:

```bash
sudo node server.js
# أو (الأنظف على لينكس): امنح Node صلاحية المنفذ مرة واحدة
sudo setcap 'cap_net_bind_service=+ep' $(which node)
node server.js
```

أول تشغيل يطبع **رمز دخول اللوحة**، احفظه:

```
⚠️  أُنشئ رمز دخول للوحة: 481902  (غيّره من الإعدادات)
[dns] خادم DNS يستمع على 0.0.0.0:53 (UDP)
[web] لوحة التحكم: http://localhost:8081
```

افتح اللوحة من الجوال أو الكمبيوتر: `http://عنوان-الجهاز:8081`
(تعرف العنوان بـ `hostname -I` على لينكس، أو `ipconfig` على ويندوز).

### متغيّرات اختيارية

| المتغيّر | الافتراضي | الغرض |
|---|---|---|
| `HOMENET_PORT` | `8081` | منفذ اللوحة |
| `HOMENET_DNS_PORT` | `53` | منفذ DNS (للتجربة بلا صلاحيات: `5335`) |
| `HOMENET_BIND` | `0.0.0.0` | العنوان الذي يستمع عليه |
| `HOMENET_PIN` | — | رمز الدخول (بدلاً من المولَّد) |
| `HOMENET_DATA` | `./data` | مجلد الإعدادات والسجلات |

للتجربة السريعة بلا صلاحيات: `npm run dev` ثم اسأل الخادم على المنفذ 5335.

## ربط الراوتر (الخطوة المهمة)

بدون هذي الخطوة التطبيق ما يشوف شيئاً.

1. **ثبّت عنوان جهاز الخادم** أولاً: من إعدادات الراوتر → DHCP → احجز عنوان
   ثابت لجهاز الخادم (مثلاً `192.168.1.10`). لو تغيّر العنوان انقطع النت عن البيت.
2. ادخل إعدادات الراوتر (غالباً `192.168.1.1` أو `192.168.8.1`).
3. ابحث عن **LAN → DHCP Server → DNS Server** (وليس WAN DNS).
4. اكتب `192.168.1.10` في الخانة الأولى، و**اترك الثانية فارغة**
   — لو كتبت `8.8.8.8` احتياطياً فالأجهزة ستستعمله وتتجاوز الفلترة.
5. احفظ، ثم أعد تشغيل الأجهزة (أو أطفئ الواي‑فاي وشغّله) حتى تأخذ الإعداد الجديد.

خلال دقائق تبدأ الأجهزة بالظهور في تبويب «الأجهزة».

> **ملاحظة:** بعض راوترات المزوّدين (STC / موبايلي / زين) تخفي خانة DNS في
> إعدادات DHCP. الحل: عطّل DHCP في الراوتر وشغّل خادم DHCP على جهاز الخادم،
> أو استبدل الراوتر بواحد يدعم ذلك (أي راوتر بنظام OpenWrt أو MikroTik).
> بديل أبسط لو ما نفع شيء: اضبط DNS يدوياً على أجهزة الأولاد فقط.

## تشغيله دائماً (systemd على لينكس/راسبيري باي)

```ini
# /etc/systemd/system/homenet.service
[Unit]
Description=شبكة البيت — خادم DNS ولوحة تحكم
After=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/home/pi/homenet
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=5
Environment=TZ=Asia/Riyadh

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now homenet
sudo journalctl -u homenet -f
```

> اضبط `TZ` على منطقتك، لأن أوقات النوم والجداول تعتمد ساعة الجهاز.

## الاستخدام

### الأجهزة والملفات
كل جهاز جديد يظهر تلقائياً. سمِّه («آيباد سارة»)، واختر له ملفاً:

| الملف | يحجب | وقت النوم |
|---|---|---|
| **طفل** | إباحي، ميسر، تعارف، تجاوز الفلترة، إعلانات، تواصل اجتماعي | ٩ مساءً – ٦:٣٠ صباحاً |
| **مراهق** | إباحي، ميسر، تعارف، تجاوز الفلترة | ١١:٣٠ مساءً – ٦ صباحاً |
| **بالغ** | لا شيء | — |
| **ضيف / غير معروف** | إباحي، ميسر، تجاوز الفلترة | — |

كل ملف تعدّله من تبويب «القواعد»: الفئات المحجوبة، البحث الآمن، وأوقات المنع
(تقدر تضيف أكثر من فترة: وقت النوم، وقت المذاكرة، وقت الصلاة…).

### التحكم اللحظي
- **قطع النت** من الترويسة: يوقف الإنترنت عن البيت كله (لمدة تحدّدها أو حتى ترجعه).
- **اقطع ساعة / اقطع للأبد** على بطاقة الجهاز: يخص هذا الجهاز فقط.
- **تمديد ٣٠ د**: يتجاوز وقت النوم مؤقتاً لهذا الجهاز (لما يحتاج يخلّص واجب).
- زر **احجب** بجانب أي موقع في القائمة الحيّة: يحجبه على كل البيت فوراً.

### التنبيهات
عند محاولة فتح موقع من الفئات الخطرة يظهر تنبيه أحمر في اللوحة. ولتصلك على
جوالك: الإعدادات → التنبيهات، وضع إما رابط ويب‑هوك، أو بوت تلجرام
(أنشئ بوتاً من [@BotFather](https://t.me/BotFather)، وضع الرمز ومعرّف محادثتك).
التنبيه محدود بمرة كل ١٠ دقائق لكل جهاز وفئة حتى لا يزعجك.

### قوائم الحجب
تبدأ بقائمة مدمجة (~٢٠٠ نطاق) تكفي للمواقع المشهورة. من الإعدادات → «حدّث
القوائم الآن» تجلب قوائم عامة كبيرة (عشرات الآلاف من النطاقات الإباحية
والإعلانية). القوائم تُحفظ في `data/lists/`.

### البحث الآمن
مُفعّل افتراضياً: يجبر جوجل ويوتيوب وبينج و DuckDuckGo على نسخها المقيّدة،
فلا تظهر نتائج ولا صور إباحية حتى لو ما كان الموقع نفسه محجوباً.

## منع الالتفاف

الحجب عبر DNS يكفي للأولاد الصغار، أما المراهق المجرّب فيحتاج طبقة ثانية.
كلها إعدادات في الراوتر، وتزيد قوة التطبيق كثيراً:

1. **حجب DNS الخارجي:** امنع خروج المنفذ `53` (UDP و TCP) لأي جهاز غير جهاز
   الخادم. عندها لو غيّر الابن DNS جهازه إلى `8.8.8.8` ما راح يشتغل عنده شيء.
2. **حجب DNS المشفّر (DoT):** امنع المنفذ `853` كذلك.
3. **DoH داخل المتصفح:** التطبيق يحجب خوادم DoH المعروفة أصلاً (فئة «تجاوز
   الفلترة»)، ومنها `use-application-dns.net` الذي يجعل فايرفوكس يعطّل DoH تلقائياً.
   على كروم/إيدج: عطّل «استخدام DNS آمن» من إعدادات المتصفح.
4. **ترحيل آبل الخاص (iCloud Private Relay):** محجوب ضمن نفس الفئة، ويُفضّل
   إطفاؤه من إعدادات الآيفون: الإعدادات ← Apple ID ← iCloud ← الترحيل الخاص.
5. **VPN:** أشهر التطبيقات محجوبة بالاسم، ويُفضّل معها تفعيل «وقت الشاشة»
   على الآيفون أو Family Link على أندرويد لمنع تثبيت تطبيقات جديدة.
6. **بيانات الجوال:** خارج نطاق أي حل شبكي — علاجها في إعدادات الجوال نفسه
   (وقت الشاشة / Family Link) أو من باقة المشغّل.

## الخصوصية والأمانة

- كل السجلات في `data/` على جهازك، ولا تُرسل لأي خادم خارجي. مجلد `data/`
  مستثنى من git.
- مدة الحفظ الافتراضية ٣٠ يوماً ثم تُحذف تلقائياً (تغيّرها من الإعدادات).
- اللوحة محمية برمز دخول، وتعرض سجل تصفّح أهل البيت — لا تفتحها على الإنترنت
  ولا توجّه لها منفذاً من الراوتر.

**نصيحة تربوية، وهي جزء من التطبيق لا زيادة عليه:** أخبر أولادك أن شبكة البيت
فيها فلترة وأنك ترى المواقع (لا المحادثات). الرقابة المعلنة تربّي وتحمي، والمخفية
تنكشف يوماً وتكسر الثقة. ولا تستخدم هذا التطبيق على شبكة ليست شبكتك ولا على
أشخاص بالغين بلا علمهم.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| `EACCES` عند التشغيل | المنفذ ٥٣ يحتاج صلاحيات: `sudo` أو `setcap` (فوق) |
| `EADDRINUSE` | شيء آخر يستعمل المنفذ ٥٣. على أوبنتو: `sudo systemctl disable --now systemd-resolved` ثم اكتب `nameserver 127.0.0.1` في `/etc/resolv.conf` |
| ما ظهرت أي أجهزة | الراوتر ما زال يوزّع DNS القديم؛ راجع خطوة الربط وأعد تشغيل الأجهزة |
| الأجهزة تظهر بعنوان IP بلا MAC | جدول ARP يحتاج الجهاز في نفس الشبكة الفرعية؛ لا يؤثر على العمل، فقط سمِّ الجهاز يدوياً |
| موقع مهم انحجب بالغلط | زر «اسمح» بجانبه في القائمة الحيّة — السماح يتقدّم على كل القواعد |
| انقطع النت عن البيت كله | أوقف التطبيق مؤقتاً، وأرجع DNS في الراوتر إلى `1.1.1.1` لحين إصلاح المشكلة |

## البنية

```
homenet/
├── server.js           لوحة التحكم + تشغيل خادم DNS
├── lib/
│   ├── dns.js          قراءة حزم DNS وبناؤها (RFC 1035) بلا مكتبات
│   ├── resolver.js     خادم DNS: استقبال، قرار، تحويل، ذاكرة مؤقتة
│   ├── policy.js       محرّك القواعد: فئات، قوائم، جداول، قطع
│   ├── store.js        الإعدادات والسجل والإحصاءات (ملفات JSON محلية)
│   ├── devices.js      التعرّف على الأجهزة (ARP) وتسميتها
│   ├── categories.js   القوائم المدمجة + البحث الآمن + مصادر التحديث
│   ├── lists.js        تحميل قوائم الحجب الكبيرة
│   └── notify.js       تنبيهات الويب‑هوك وتلجرام
├── public/             اللوحة (HTML/CSS/JS عربية RTL)
└── test/selftest.js    اختبار ذاتي كامل بلا إنترنت
```

## الاختبار

```bash
npm test
```

يشغّل خادم DNS حقيقياً مع «خادم أعلى» وهمي محلي، ويتحقق من: ترميز حزم DNS،
الحجب بالفئة، أولوية قائمة السماح، أوقات المنع العابرة لمنتصف الليل، الذاكرة
المؤقتة، البحث الآمن، التسجيل، التنبيهات، وطلبات TCP.
